## Current project

### ColdFlow 📬

An automated cold outreach platform for agencies and freelancers. Type in a niche and a city, and ColdFlow finds matching businesses, audits their websites for obvious problems (slow loading, no mobile layout, missing SSL), then writes a personal first email with the OpenAI API based on what it found. Follow ups go out on a schedule until someone replies, and every reply lands in one shared inbox.

Currently in private beta with three agencies, averaging an 11% reply rate.

**Built with** TypeScript, Next.js, Express, MongoDB on Aiven, n8n, OpenAI and Stripe, hosted on Vercel

**Progress**

* [x] Lead scraping and website audits
* [x] AI written first emails with tone presets
* [x] Follow up sequences through n8n
* [ ] Reply detection and shared inbox
* [ ] Stripe subscriptions and usage limits
